# c-learning-scripts-u
This is a homework repository for C Programming at university(2026).

## prog1.c
999以下の自然数を入力すると、位ごとに数を分離して画面表示するプログラム

## prog2.c
3つの整数x、m、nをキーボードから入力したとき、xがmとnの公倍数かどうかを判定した結果を表示するプログラム

## prog3_1.c
**While文**を用いた二つの整数m、nを入力すると、mからnまでの（mとnを含むものとする）整数の合計を計算して画面に表示するプログラム

## prog3_2.c
**for文**を用いた二つの整数m、nを入力すると、mからnまでの（mとnを含むものとする）整数の合計を計算して画面に表示するプログラム

## prog4_1.c
単精度型(float型)変数で2のべき乗を繰り返し計算し、その結果を画面に表示するプログラム

## prog4_2.c
倍精度型(double型)変数で2のべき乗を繰り返し、その結果を画面に表示するプログラム

## prog4_3.c
品物の定価と割引率（％）を入力し、割引後の価格を求めるプログラム.
ただし割引後の価格に消費税（10%）も加算し、小数点以下の数値を切り捨てた結果を表示すること。

## prog5.c
単精度(float)型変数fnumの初期値を0.0 に設定した後、0.1をn回繰返し加算したときのfnumの値を画面に表示するプログラム
