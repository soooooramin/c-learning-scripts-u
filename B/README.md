## prog8_2.c
手順 a), b) に従って二種類の関数を定義し、c) に示す時刻（time_aとtime_b）の時間差を求めるプログラム(prog8_2.c)を、関数timeおよび hhmmssを用いて作成しなさい。
(注)　a）, b) はプログラムを完成させるために必要な作成手順なので、レポートはc）で作成したプログラム (prog8.c) を提出すること！

a)	（値渡しを用いた関数）
３つの整数変数として時(hh)・分(mm)・秒(ss)を引数として与えると、返り値に、０時０分０秒からの通算秒数（トータル秒）を返す関数
　　　int time(int hh, int mm, int ss)
を作りなさい。

b)	（参照渡しを利用した関数）
次に、トータル秒(total)を引数に与えると、時(hh)・分(mm)・秒(ss)を返す関数 
void hhmmss(int total, int *hh, int *mm, int *ss)
を作りなさい。　
　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　
c)	上記で作成した二つの関数を用いて、二つの時刻（time_aとtime_b）の間の時間差を求めるプログラム(prog8.c)を作成しなさい。ただし time_a ＞ time_bのときは0時をまたいだ時間差を計算すること。
ヒント：time_a, time_bは、それぞれhh, mm, ssに相当する数をキーボードから
        3個づつ入力する。time_a, time_b それぞれのトータル秒を求めた後に、
　　　　時間差（秒）を求め、その時間差を時・分・秒に変換するのが簡単。

## prog10.c
以下に示す３行×４列のデータが格納されたファイル test.txt からデータを読み出し、各行の平均および各列の平均を求めた結果を result.txtに書き出すプログラム (prog10.c)を作成しなさい。
      ただし平均点は小数第2位までの結果を出力すること！単純に小数第2位までを表記するだけで構いません。（余力があれば、「小数第3位を四捨五入」した結果を出すプログラムを作ってください。意識的に四捨五入の処理を正しく定義しているプログラムは、「発展問題」相当とみなして、加点します。）

注： test.txt はレポート課題提出ページで提供するので、ダウンロードして使用すること。
ヒント：平均値の求め方自体は、Cプログラミング序論B第1回レポートと（小数点以下の桁数指定を除き）同一なので、ファイルの読み書きができれば解答できます。
